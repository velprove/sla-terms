About this dataset

Schedules are extracted from each provider's publicly documented standard SLA terms. Different services within the same provider may have slightly different tiers (for example, AWS S3 differs from EC2). Enterprise contracts often have custom terms. This is not legal advice. For any commercial claim, verify against the actual contract text you signed.

Each entry links to the provider's official SLA page so you can confirm current terms. If terms change, file an issue or PR on the GitHub repo.

Maintained by Velprove, an uptime monitoring service that watches whether your site or service actually hits its SLA. The data here powers the SLA Credit Calculator on velprove.com.
